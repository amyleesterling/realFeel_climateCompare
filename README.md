# realFeel_climateCompare

**[Live Site](https://amyleesterling.github.io/realFeel_climateCompare/)**

Compare the climate of two cities in a game-show-style showdown using 20 years of historical weather data. Powered by [Open-Meteo](https://open-meteo.com/).

- Real Feel, Temperature, Wind, Sunshine, Precipitation
- Comfort Score (0-100) crowns the more pleasant city
- Monthly breakdowns with interactive charts
